How Vendor Coverage Works

1. Validation Submission
In-app validations are submitted via the SpecTrace SDK. Each validation includes a vendor name, requirement link, and optional feature flags.
2. Pass Rate Calculation
Pass rates are calculated from the latest validation result for each vendor's validations. Green (≥90%), yellow (≥70%), red (<70%).
3. Regression Detection
A regression is flagged when a validation that passed in a previous run now fails. This helps catch integration breakages early.
4. Feature Flag Tracking
Feature flags submitted with validations are aggregated per vendor, showing which flags are active across which validations.
SDK Usage: spectrace.submit_validation(req_id, vendor="Stripe", flags={"use_new_auth": True}) See the SDK documentation for full integration details.
