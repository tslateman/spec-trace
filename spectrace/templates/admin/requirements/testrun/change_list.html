How Test Runs Work

1. Capture CI Output
Each test run represents a single CI execution imported from pytest/JUnit output.
2. Preserve Raw Detail
Test runs store commit metadata, branch, and exact counts before linking to requirements.
3. Feed Verification Runs
Once tests are linked, these results drive verification status for requirements.
CLI Usage: pytest --junitxml=results.xml python manage.py import_results results.xml --links links.json Use to record raw test runs before verification linkage.
