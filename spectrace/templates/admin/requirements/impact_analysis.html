How Impact Analysis Works

1. Git Diff
Compares spec files between two git refs (branches, commits, or tags) to find which .md files changed.
2. Extract Requirements
Parses changed spec files to extract requirement IDs from YAML frontmatter.
3. Hierarchy Expansion
If "Include child requirements" is checked, finds all descendant requirements. A change to a parent affects all children.
4. Test Lookup
Queries TestRequirementLink to find all tests linked to affected requirements via @pytest.mark.requirement().
CI Usage: ./manage.py impact_analysis main HEAD --format json Exit code 1 if tests are affected — use to gate PR merges or trigger targeted test runs.
