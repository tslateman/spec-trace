Getting Started with SpecTrace

See which requirements are verified by passing tests. Requirements as code, automatically verified.

What is SpecTrace?

SpecTrace connects product specifications to verified code. Write requirements as markdown files in your repository, link them to pytest tests, and see live verification status in a dashboard.

No more spreadsheets. No more "is this requirement tested?" The answer is always one click away.

Learn more about the concepts behind SpecTrace

1 Write Your First Spec

Specs are markdown files with YAML frontmatter. The frontmatter defines metadata like ID, title, and priority. The body describes the requirement in plain language.

specs/auth.md
---
id: REQ-AUTH-001
title: User Login
priority: high
verification_method: test
---

Users must authenticate with email and password.

## Acceptance Criteria

- Email validation checks format
- Password strength requirements enforced
- Session created on successful authentication

Save this file as specs/auth.md in your repository. The id field is what you'll reference in tests.

Import specs into SpecTrace with this command: 

python manage.py parse_specs specs/

2 Link Tests with Pytest Markers

Use the @pytest.mark.requirement() decorator to link tests to requirements. When tests pass, the linked requirement is marked as verified.

tests/test_auth.py
import pytest


@pytest.mark.requirement("REQ-AUTH-001")
def test_user_can_login():
    """Test successful login with valid credentials."""
    # Your test logic here
    assert True


@pytest.mark.requirement("REQ-AUTH-001", "REQ-AUTH-002")
def test_login_creates_session():
    """One test can verify multiple requirements."""
    assert True

Run tests and export results: 

# Run tests with JUnit XML output
pytest --junitxml=test_results.xml

# Extract requirement-test links
python manage.py extract_links --output links.json

3 View Dashboard Results

Import test results and see verification status in the dashboard. 

# Import test results
python manage.py import_results test_results.xml --links links.json

# Start the server
python manage.py runserver

# Open http://localhost:8000/admin/

What You'll See

PASS All linked tests pass
FAIL Any linked test fails
UNTESTED No tests linked

The traceability matrix shows every requirement with its verification status. Click any requirement to see which tests verify it, and drill down to individual test results.
