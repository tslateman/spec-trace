How Verification Runs Work

1. Import Results
CI outputs are imported from pytest/JUnit runs and normalized into a single verification batch.
2. Link to Specs
Each test result maps to requirements via @pytest.mark.requirement() or link metadata.
3. Compute Status
Requirements are marked passing, failing, or untested based on linked test outcomes.
CLI Usage: pytest --junitxml=results.xml python manage.py import_results results.xml --links links.json Use to refresh verification run history after CI executes.
