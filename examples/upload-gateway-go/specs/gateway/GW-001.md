The gateway is the only door into the upload pipeline. It admits the media
types the pipeline can process, caps the bytes a single upload may carry, and
holds each tenant to its request budget.

## Acceptance Criteria

- Every accepted upload names a supported media type
- Every accepted upload fits the size cap
- Every tenant stays within its request budget
