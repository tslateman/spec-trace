The vault holds documents the pipeline has processed. It seals every document
before it lands, names the key that sealed it, and forgets a document once its
retention window closes.

## Acceptance Criteria

- Every stored document is sealed
- Every stored document names the key that sealed it
- No document outlives its retention window
