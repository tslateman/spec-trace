Sample epic for demonstrating requirement hierarchy. This represents a top-level business capability.

## Overview

The Sample Platform demonstrates SpecTrace's ability to track requirements at multiple levels of granularity - from high-level epics down to specific user stories.

This epic encompasses authentication and API capabilities, showing how complex business domains can be broken down into manageable features and verified through automated tests.

## Acceptance Criteria

- All child features are properly linked via parent relationships
- Requirements can be navigated via parent-child relationships
- Verification status rolls up from stories to features to epics
- Both test-based and manual verification methods are supported
- Requirement depth is correctly calculated for hierarchy visualization
