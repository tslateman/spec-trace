# Workspace Sharing & Collaboration

Users must be able to invite others to their workspaces.

## Requirements

1. **Internal Sharing**: Workspace owners MUST be able to grant other tenant users access to a Workspace.
2. **External Sharing**: If enabled on the tenant's subscription, users MUST be able to generate secure, time-limited, read-only links for external stakeholders.
3. **Revocation**: Workspace owners MUST be able to immediately revoke an external sharing link.
