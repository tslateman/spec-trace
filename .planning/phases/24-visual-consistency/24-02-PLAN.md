1. Add design system include at top of {% block content %}:

   - These are status-specific colors (improved/regressed/etc) that need to stay as inline styles since they're semantic for this page

3. Update the main table (line 134) from `class="w-full"` to `class="st-table"`:
   ```html
   <table class="st-table">
   ```

4. Update thead - remove Tailwind classes, let .st-table handle it:
   ```html
   <thead>
       <tr>
           <th>Change</th>
           ...
       </tr>
   </thead>
   ```

5. Update th elements - remove inline Tailwind classes like `px-4 py-3 text-left text-sm font-medium text-base-700 dark:text-base-300`

6. Update tbody - remove Tailwind divide classes, let .st-table handle borders:
   ```html
   <tbody>
   ```

7. For td elements - keep the change-type classes (change-improved, etc) but remove redundant padding classes since .st-table provides padding

Note: Keep the card/layout Tailwind classes (bg-white, rounded-lg, etc) - only migrate the TABLE to .st-table
