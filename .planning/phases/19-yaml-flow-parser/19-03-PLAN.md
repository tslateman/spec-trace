# Phase 19 Plan 03: Single File Support for parse_flows

**Fix parse_flows command to accept both single YAML files and directories**

## Context

From UAT Test 2: User expected `parse_flows flows/linear-connection.yaml --dry-run` to work, but command only accepts directories.

Root cause: `path_must_be_dir=True` inherited from BaseImportCommand, and `do_import` only calls `parse_directory()`.

## Tasks

### Task 1: Add single file support to parse_flows command

**File:** `spectrace/requirements/management/commands/parse_flows.py`

**Changes:**
1. Set `path_must_be_dir = False` class attribute
2. Update `path_argument_help` to indicate both files and directories are accepted
3. In `do_import()`, detect if path is file or directory:
   - If file: call `parser.parse_file(path)` and wrap result in list if not None
   - If directory: call `parser.parse_directory(path)` as before

**Verification:**
```bash
python spectrace/manage.py parse_flows flows/linear-connection.yaml --dry-run
```
Should output flow details without "Path is not a directory" error.
