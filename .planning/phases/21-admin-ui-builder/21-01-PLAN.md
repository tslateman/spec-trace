<task type="auto">
  <name>Task 2: Create flow editor service module</name>
  <files>spectrace/requirements/flow_editor.py</files>
  <action>
Create `spectrace/requirements/flow_editor.py` with these functions:

1. **FLOWS_DIR constant**: `Path(settings.BASE_DIR).parent / "flows"` - the flows directory

2. **validate_flow_path(file_path: str) -> Path**:
   - Takes relative path like `linear-connection.yaml`
   - Resolves against FLOWS_DIR
   - Validates: within FLOWS_DIR (no `..` traversal), ends with `.yaml` or `.yml`
   - Returns resolved Path or raises PermissionError/ValueError

3. **get_flow_files() -> list[dict]**:
   - Scan FLOWS_DIR for `**/*.yaml` and `**/*.yml`
   - For each file, try parse with YAMLFlowParser
   - Return list of dicts: `{path, name, title, valid, error, step_count}`
   - Handle FlowParseError gracefully (return with error message)

4. **load_flow_for_editing(file_path: str) -> dict**:
   - Validate path with validate_flow_path
   - Load using ruamel.yaml (preserves comments)
   - Return raw dict (not FlowDef) for form editing

5. **save_flow(file_path: str, data: dict) -> None**:
   - Validate path with validate_flow_path
   - Validate content using YAMLFlowParser._validate_and_build_flow (raises FlowParseError on invalid)
   - Write using ruamel.yaml with `yaml.indent(mapping=2, sequence=4, offset=2)`
   - Preserves existing comments via round-trip mode

6. **FlowEditorError(Exception)**: Custom exception for editor-specific errors

Import ruamel.yaml like this:
```python
from ruamel.yaml import YAML
yaml = YAML()
yaml.preserve_quotes = True
```

Do NOT auto-sync to database on save. The save function only writes to disk.
  </action>
  <verify>Run `python -c "from requirements.flow_editor import get_flow_files, load_flow_for_editing, save_flow; print('OK')"` succeeds</verify>
  <done>flow_editor.py exists with all 5 functions, path traversal blocked, ruamel.yaml used for round-trip</done>
</task>
