  <name>Task 1: Add Alpine.js linearHealthWidget component</name>
  <files>spectrace/templates/admin/index.html</files>
  <action>
Add the linearHealthWidget() JavaScript function inside a script tag at the end of the content block (before the closing div).

The component must include:
1. State properties: status ('unknown'), message (''), lastChecked (null), isLoading (false), error (null)
2. Computed property statusLabel: maps status to display text (Healthy/Degraded/Unhealthy/Unknown)
3. Computed property statusClass: maps status to CSS class + base styles
   - healthy -> 'status-passing' (existing green class)
   - degraded -> 'status-untested' (existing yellow class)
   - unhealthy -> 'status-failing' (existing red class)
   - unknown -> 'bg-base-200 dark:bg-base-700 text-base-600 dark:text-base-400' (gray)
4. Computed property lastCheckedText: relative time display ("Last checked X ago")
5. async fetchHealth(): GET /api/integrations/linear/health/, update state from response
6. async testConnection(): POST /api/integrations/linear/test-connection/, update state, handle errors, always reset isLoading in finally block
7. updateFromResponse(data): shared logic to extract status, message, lastChecked timestamp from API response

Use native fetch (no libraries). Extract timestamp from data.checks[0].timestamp if available.

Also add x-cloak CSS rule in the existing style block: `[x-cloak] { display: none !important; }`
  </action>
