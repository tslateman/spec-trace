  <action>
Create `run_flow.py` management command:

**Arguments:**
- `flow_id` (positional): Flow ID (numeric) or name (string)
- `--context` (optional): JSON string with execution context
- `--timeout` (optional): Flow timeout in seconds (default 300)
- `--step-timeout` (optional): Per-step timeout in seconds (default 60)

**Flow lookup logic:**
1. Try `int(flow_id)` - if successful, lookup by pk
2. If ValueError or DoesNotExist, lookup by name
3. If both fail, raise `CommandError(f"Flow not found: {flow_id}")`

**Execution:**
- Parse `--context` JSON if provided (catch JSONDecodeError, raise CommandError)
- Create `SequentialFlowEngine` instance
- Call `engine.execute(flow, context, source=VerificationFlowSource.MANUAL, step_timeout=..., flow_timeout=...)`

**Output format:**
```
Flow: {flow.display_name} ({flow.name})
Status: {run.status}
Duration: {run.duration_ms}ms

Steps:
  [PASS] Step Name
         Details: {step.details}
  [FAIL] Step Name
         Error: {step.error_message}
```

**Exit codes:**
- Return `None` (exit 0) if flow passed
- Call `sys.exit(1)` if flow failed

**Style notes:**
- Use `self.style.SUCCESS` for [PASS]
- Use `self.style.ERROR` for [FAIL]
- Use `self.style.WARNING` for flow status when failed
